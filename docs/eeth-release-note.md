# Group Enrichment — Clarifying Description

The **group-enrichment** feature adds a contact intelligence panel that shows:

- Which groups a contact is part of
- Key activity summaries per group (topics, decisions, blockers, mentions)
- Refreshable and cached results for faster loading

This implementation and stabilization pass was completed by **Eeath**.
